# Screen catalogue

Taken on the AVD `mintube_tablet` (2560x1600, 320 dpi), build `app-debug.apk` from master eb710bc, anonymous, live network. Light = default, dark via `cmd uimode night yes`.

Coverage is PARTIAL. Not shot: phone-size set (`docs/screens/phone/` is empty), tablet-portrait set beyond 4 shots, dark variants of Settings-advanced/About-detail/Download-options/Shorts-comments/sign-in, post detail, mini-player (retest of the rebuilt mini-player on 476751d was blocked, see QA_REPORT.md). Reason: the emulator host was overloaded (load average 15-23, repeated ANRs and multi-second frames).

`docs/screens/tablet/` = tablet LANDSCAPE. `docs/screens/tablet-portrait/` = tablet PORTRAIT. `docs/screens/qa/` = per-feature evidence, named by matrix row id or scenario.
