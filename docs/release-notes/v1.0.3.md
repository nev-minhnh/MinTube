MinTube 1.0.3 fixes scrolling on wide screens.

## Fixed

- **The empty strips on wide screens now scroll.** On a tablet in landscape, search results sit in a centred column with an empty strip on each side. Swiping in those strips did nothing. Now they scroll the list like the rest of the screen.
  - Search (All, Channels, Shorts)
  - History
  - Playlists
  - Playlist search
  - All subscriptions
  - Settings
