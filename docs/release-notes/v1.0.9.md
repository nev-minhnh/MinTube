MinTube 1.0.9 can update itself.

## New

- **Download and install updates from inside the app.** In Settings → About, tap Check for updates. When a newer version exists, a dialog shows the version, what changed and the download size, with Download and install and Later.
  - The download shows its progress and can be cancelled.
  - The file is checked against the release's SHA-256 checksum before anything is installed; a file that does not match is deleted.
  - The first time, Android asks you to allow MinTube to install apps. After you allow it, return to MinTube and the install continues.
  - Android then shows its own confirmation and replaces the app in place. Your data stays.
