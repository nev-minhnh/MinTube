MinTube 1.0.13 keeps long videos playing through network changes.

## Fixed

- **Playback no longer stops with "MEDIA_SESSION_CHANGED" on long videos.** When the network route changes during playback (a VPN reconnecting, Wi-Fi roaming), MinTube refreshes the video's links and carries on. It could do that only once per video, so a second change later in the same video stopped playback with an error. The refresh is now available again once the video has played on normally for 30 seconds since the last one. A refresh that fails again straight away still stops after one try, so it cannot loop.
