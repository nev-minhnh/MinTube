MinTube TV 1.0.7 lets you make the whole interface smaller.

## New

- **Interface size.** Settings → Display → Interface size offers 25%, 50%, 75% and 100% (the default). The choice shrinks text and layout together on every screen, so a TV that shows MinTube TV too large can fit everything on screen, including the sign-in code. It applies at once and is remembered.
  - Display is the second section in Settings, right under Account, so it is easy to reach even when the interface is too large.
