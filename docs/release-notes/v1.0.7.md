MinTube 1.0.7 applies the whole-unit rule to every publish time.

## Changed

- **YouTube's own rounded text follows the same rule as real dates.** "7 days ago" now reads "1 week ago", "14 days ago" reads "2 weeks ago", "30 days ago" reads "1 month ago" and "24 hours ago" reads "1 day ago". Other values ("6 days ago", "23 hours ago") stay as they are. The Upload date filter is unchanged.
