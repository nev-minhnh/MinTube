MinTube TV 1.0.11 fills in view counts and publish times on every card.

## Fixed

- **Cards on a signed-in TV now show views and publish time.** Signed-in rows (Recommended, Music, Subscriptions, channel pages, playlists, Watch later, Up next) often arrive with only the title and channel. The phone app already read the missing details in the background; MinTube TV now does the same on every screen, so each card ends with "views · time" once the details arrive. The page still appears immediately.
