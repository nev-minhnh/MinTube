MinTube 1.0.14 fills in the video description when you are signed in and squares the comments sheet.

## Fixed

- **The Description card is no longer empty when signed in.** The signed-in watch page response leaves out the video description, and MinTube only fetched the public details when the date or channel was missing. A missing description now fetches them too, so the description (and its links) shows again on phone and tablet.

## Changed

- **Comments sheet with square corners.** On phones the comments sheet no longer has rounded top corners; it now matches the tablet layout.
